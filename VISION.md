# Vision

TimeWatcher helps people understand where their working time goes.

It starts with a simple premise: time should be easy to record while
you work, without interrupting the work itself.

Project overview and developer documentation: [`README.md`](./README.md)

TimeWatcher should make it effortless to:

- clock in and out
- track what task you're working on
- switch between tasks
- understand how long you've spent working
- see how your time is distributed across days and tasks
- review your working patterns over time

The interface should stay lightweight and keyboard-first. TimeWatcher
should remain useful without requiring a cloud account, complex setup,
or constant interaction with the application.

The long-term goal is to build a reliable instrument for observing how 
time is actually spent.

## Current Focus

### Priority

- Clear session and task semantics
- Reliable time and duration calculations
- Task switching
- Break Tracking
- Fast CLI workflows

### Next Priorities

- Daily and task-based aggregation
- Basic session statistics
- Improved CLI ergonomics
- Documentation and CI
